## Desired Component System

Prefer reusable components such as:

SynButton
SynInput
SynAvatar
SynCard
SynHeader
SynListItem
SynBadge
SynModal
SynEmptyState

Do not duplicate the same styling across screens.

---

## Icons

Use Ionicons for standard interface icons.

Only import custom assets from the Figma project when
they are genuinely custom illustrations or brand assets.

---

## Design Philosophy

Syn should feel:

- private
- friendly
- modern
- lightweight
- intimate
- social without being performative

Primary brand direction:

Orange-first with blue accents.
